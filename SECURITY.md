# Security Policy

## Supported Versions

Security fixes are released on the latest `indiecorns` npm version.

## Reporting a Vulnerability

Report security issues privately by emailing hello@danielsinewe.com.

Please include:

- The affected version.
- A concise description of the issue.
- Reproduction steps or proof of concept, if available.
- Any known impact or mitigation.

Do not open a public GitHub issue for suspected vulnerabilities.

## Secrets

This repository must not contain production secrets, access tokens, private
keys, customer data, or local authentication state. Use environment variables
or the hosted Indiecorns app configuration for secrets.
